# v0.82.0 — Tournament ready

Tools to run a tournament, steadier pods, and games that ride out a server hiccup.

## New

- **A room leader can now fix a tournament match from its ⋯.** Restart the current turn, give one game or the whole match to a player, or replay a match from 0–0. The menu also shows how the game stands: whose turn it is, what each player is being asked and for how long, and their clocks.
- A game restarted from its turn is kept as its own replay.
- Organisers can send a stuck game's questions to its players again.

## Changed

- Clicking a planeswalker always lists all of its abilities, with the ones it can't pay greyed.

## Fixed

- A Hideaway card sits face down under the land that hid it, and is gone once you play it. (@coffeetraveler)
- A Hideaway land with nothing under it no longer holds your priority. (@coffeetraveler)
- Making a room, locking a deck or starting a match no longer freezes every table while the disk is slow.
- An AI-vs-AI pod game whose game server drops out is played again instead of settled without a result.
- A room leader can correct a finished match of the round in play from its ⋯.
- Delete account takes you to hadoku.me's home again, not back in as a new guest.
- A short server hiccup no longer rewinds your game to the start of the turn.
- An Offspring token copy keeps its abilities after a game moves server or restarts its turn.
- Restart turn and a server move keep Season effects and stolen creatures as they were.
- On a phone, a room keeps the same edge on both sides.
- On a phone, a tournament table's two players show whole.
- A table's Enter game button no longer looks like an underlined link.
- The draft's side column fits beside the pack after the window shrinks.
- A pick timer turned on mid-draft shows on every screen at once.
- While the table builds decks, the room bar counts drafters as people, not open seats.
- A drafter who leaves mid-draft is out of the event from round 1, so nobody waits at an empty table.
- A player who leaves or is disqualified is no longer paired in later rounds.
- Closing your tab during a round no longer gives your seat away.
- Swiss with bots no longer pairs the same two players again while someone new is free.
- A drafter who leaves mid-draft no longer freezes the draft: their seat picks for itself.
- The second pod of a split room uses the room's pick timer and bot setting too.
- A long name on the podium wraps instead of being cut short.
- On a tablet with chat open, the podium fits its column.
- The front page loads faster: the replay list no longer re-reads every game.
- Opening the replay list on a busy server no longer stalls games in progress.
- A game no longer freezes when the server restarts mid-question.
- Both players pressing ready at once no longer shows "the match has already started".
- A game starting on a freshly set-up game server is no longer stopped while it boots.
- "Play here instead?" after a server restart clears by itself once the old tab is gone.
- A game server reconnecting can no longer crash the server.

## Fixes

- Tournament checks: whole pods, leavers, restarts, failovers and a fire drill, in real games.
- A tournament runbook for organisers.
- Steadier, faster checks before an update ships.
- Better server health reports.
- Art for the cards the new checks play.
