# v0.55.0 — Bots that draft

Draft bots now pick with a model trained on real cube drafts, and a card you opened early on a phone gains its Cast button.

## New

- **Draft bots draft like real cube drafters.** They pick with CubeCobra's draft model, trained on real cube drafts. When it can't answer in time, they fall back to the cube's pick order. (@thyeggman)

## Fixed

- On a phone, a card you opened just before your turn's priority arrived now shows its Cast button when it does, instead of staying empty until you closed and reopened it.

## Fixes

- A browser reloading the site in a loop is now slowed down, so it can't flood the logs.
- Steadier timing checks before an update ships, and the daily health watch reads the backups correctly.
- Hosting and setup for the new draft bots: every card carries its Scryfall id, the game servers run the model with a backup, and a hidden room setting splits a pod between the model and the pick order to compare them.
