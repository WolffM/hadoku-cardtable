# v0.36.0 — Clearer turns and choices

Passing, picking and whose turn it is are all easier to read at a glance.

## New

- **The table dims while you pick.** While you choose a target, attackers or blockers, the rest of
  the table goes dark so the cards you can pick stand out.

## Changed

- **Next Phase has moved into the question box.** When the game waits on you it asks "Proceed to
  Combat?" (or whichever step is next) with a Next Phase button. With a spell on the stack it asks
  "Resolve <spell>?" with a Resolve button, and Done Attacking and Done Blocking sit at its bottom left.
- Whose turn it is is easier to see: a brighter edge light, in your colour on your turn.
- Choices with two options, like a man-land's colour, sit together instead of split apart.
- Every page uses the same plain back arrow.

## Fixed

- Auras and equipment on an opponent's creature show on that creature.
- The game no longer stops for a man-land that could not fight.
- A land tapped for mana can be untapped while a question is open.
- The phase list keeps animating after a fast run of phases.

## Under the hood

- A slot for combat drums in the sound builder, with takes to choose from.
- Refused clicks on the board are logged, to track down cards that won't respond.
- Load tests and frame-rate measurements for busier tables.
- Faster, steadier checks before an update ships.
- Card art entries for new test scenarios.
- Planning notes for running more games at once.
- One style for every set of patch notes.
- Dependency updates.
