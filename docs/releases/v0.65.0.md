# v0.65.0 — Joined choice bars

Rows of choices read as one joined bar, a Gauntlet picks its year like Classic does, and a
character picked right after an update shows on the board.

## Changed

- Each row of choices in a room and the create form is one joined bar, so the mode, the format
  and the other options read as separate choices.
- A Gauntlet's year is picked on the same year slider as Classic's, with Random at its left end,
  and its formats are the same tabs.

## Fixed

- A character you pick just after an update restarts the server shows on the board, instead of
  your old one until the next game.

## Fixes

- A room's link preview loads only the fonts it uses.
- Updates no longer time out fetching the rules engine when its version moves.
- Dependency updates.
- Test updates.
