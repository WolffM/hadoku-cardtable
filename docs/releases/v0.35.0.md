# v0.35.0 — Pages with a title

Decks and Inventory get a proper heading, and a handful of display fixes.

## Changed

- **Decks and Inventory have a title and a back arrow.** Each page is named at the top, and the
  arrow beside the name takes you back to the lobby.

## Fixed

- **The theme picker's hover labels show properly and no longer push the chat up.**
- **Highlighted text is easy to read in every theme.**
- **Patch notes in Discord no longer break mid-sentence.**

## Under the hood

- **Testing rooms open straight into a game on their board.**
- **Faster checks before an update ships.**
- **One style for every set of patch notes.**
- **Dependency updates.**
