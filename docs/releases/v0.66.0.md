# v0.66.0 — Events from polls

Make an event straight from a poll, event rooms open for chat at once, a Gauntlet's year works
with any format, and an Experimental features switch in the settings.

## New

- **Make an event from a poll.** Whoever attached a poll can make its event from it with Create event: the poll's title, the time most people can make and the pool they ranked first come filled in, and everything stays editable. The event shows how many signed up on the poll for its start, and counts later answers too.
- An Experimental features switch in the Game settings, off by default.

## Changed

- An event's room opens for chat at once, and its seats open 30 minutes before it starts.
- Challenge is offered in Create room only with Experimental features on; Challenge rooms already made still show and can be joined.
- A Gauntlet's year slider is always there: pick a year with Random format and the Gauntlet draws Standard, Modern or Legacy from that year.

## Fixes

- Card art for more of the cards scenarios and decks place.
- A stronger computer opponent was tried and measured; it stays off.
- Dependency updates.
