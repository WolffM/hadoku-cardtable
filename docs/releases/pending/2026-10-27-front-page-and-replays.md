## New

- **A new front page.** The busiest live game plays at the top, beside the latest patch notes, upcoming events and a rotating card. When nothing is live, it plays back the latest game instead.
- **Replays.** Every game is recorded, and `#/replay/<game>` plays one back with play, pause, speed and a scrubber.

## Changed

- Rooms are cards that show at a glance whether a room is draft or constructed, a tournament, its mode and format, and what it is doing now.
- The GitHub repo is linked beside Discord in the top bar.
