## Fixed

- Opening the table no longer downloads and unpacks every music track: only the track a match plays is loaded, which saves about 47 MB of data and roughly a gigabyte of memory, so phones stay responsive.
- The front page's Discord chat and event polls appear at once instead of waiting on a slow lookup, and a Rally outage no longer stalls the polls card.

## Changed

- Sounds you have already heard stay in your browser, so coming back to the table no longer downloads them again.
