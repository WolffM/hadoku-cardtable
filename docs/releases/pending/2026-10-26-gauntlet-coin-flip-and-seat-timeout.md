## Fixed
- A Gauntlet's second game and later no longer ask play-or-draw by who lost the game before it — every Gauntlet game flips its own coin.
- A Gauntlet's last game, when only one deck is left to each side, now waits for both players to press it instead of dealing itself.
- A seat with nobody connected to it, and no match live at its table, is now given back after 30 seconds; reloading within that window keeps it.
