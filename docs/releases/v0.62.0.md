# v0.62.0 — Two months of Forge

Forge's own updates arrive: hundreds of new cards and dozens of rules fixes, and End Turn always lets you answer an opponent's spell.

## New

- **Two months of Forge's own updates are in.** 714 cards Forge couldn't play before now work, among them Marvel Darkhold Destiny and its Commander set, Nauctis The Sunken Realm, Alchemy Reality Fracture and the Unfinity sticker sheets, and 3,108 more cards play more accurately.

## Changed

- Auto pays with a Signet (or any mana source that costs mana itself) when that's the way to pay.
- Brawl decks are 100 cards, as on Arena.
- The room list updates the moment a room opens, fills or closes.
- A room's chat is now kept by cardtable itself. Messages sent before this update stay behind, so an open room starts with an empty chat once.

## Fixed

- After you press End Turn, an opponent's spell still gives you the chance to respond.
- A game whose mandatory triggers loop forever is now a draw instead of a stuck game.
- Drawing from an empty library no longer keeps trying to draw.
- Permanents that enter together no longer change how each other enters.
- Block requirements respect a blocker's limits and creatures that can't block alone.
- "Must attack" no longer counts on an attack that has a cost to pay.
- A library of exactly as many cards as a mill cost can pay that cost.
- A dig shows the cards it looked at, and cards it lets you cast from the graveyard or exile can be cast.
- Lands played earlier in the turn still count for cards that arrive later.
- Panharmonicon-style extra triggers are counted correctly.
- Several rare crashes in Camouflage, counters and choose-a-color effects are gone.
- "Your turn" no longer shows for the turn that just ended.

## Fixes

- The game engine's messages reach your screen in the order the game reads them, and a waiting message never covers a real question.
- A room's members, ready and leader run on the code every hadoku game shares.
- More music ideas for the soundtrack, and checks that say more when the AI is cut short.
