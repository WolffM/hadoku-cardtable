# v0.68.1 — Steadier clocks and stacks

A few fixes you can feel, and Cardtable's insides rebuilt so a new game can share its rooms.

## Fixed

- An ability's chip on the stack is the same shape on both players' screens, even after one of you resizes the window.
- A player whose chess clock reaches 0:00 now always loses on time, where the game sometimes sat at zero and never ended.
- Pressing Cancel on the "Yielding until end of turn" bar more than once no longer skips the window you cancelled for.

## Fixes

- Magic's code now lives in its own home, apart from the parts every game shares: its card data, deck, draft and engine packages, its server and its pages.
- Rooms run on a shared lobby that any game can use: a room's record, seats and view no longer assume Magic, and every saved room loads unchanged.
- The checks that keep Magic's code and the shared code apart see every file and every import form.
- Intermittent test failures traced and fixed: the opening deal, pacing and timing checks, and a recorder race.
- The engine's frame log names each seat's turn and phase, so a missed turn can be traced.
- Card art for the cards the new scenarios use.
- Dependency updates.
