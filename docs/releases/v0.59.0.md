# v0.59.0 — One click to attack

Attacking a lone opponent takes one click, room links unfurl in Discord, and the front page shows the latest tournament's podium.

## New

- **A room link unfurls in Discord.** Paste a room's address and it shows the room's name, what it plays (like "Modern Gauntlet 1v1"), and your avatar against an open "You?" seat, or against whoever has sat down.
- **The front page shows the latest tournament's top three.** When a tournament finishes, its podium opens the wildcard card for a week. Only a bigger tournament can take its place sooner.

## Changed

- Against a lone opponent, one click sends a creature into the attack: no arrow to drag.
- Facing a single attacker, one click on a creature blocks it.
- In combat, All now comes before Done Attacking, with more room between them.
- Revealed cards show up straight away, instead of waiting a quarter second on screen.
- The tournament standings' tie-breaker columns are headed OMW, Wins, OGW and Median; hover one for its full name.
- A room's address is now `hadoku.me/cardtable/room/<id>`. Old links with `#/room/` still open the room.

## Fixed

- Sacrificing a second Lion's Eye Diamond no longer freezes the game.
- A dual land's colour ring shows once, where you clicked, and stays put.
- A library deck's cards show the same art everywhere, and sideboarding no longer changes their printings for the next game.
- Older replays show their cards' art again.
- Picking a Gauntlet year, format, pool or mode no longer flickers back to the old choice before it sticks.

## Fixes

- A window the game is still waiting on is shown after a few seconds, so a held-back question can never leave a game silent.
- Steadier checks before an update ships: timing checks read the server's own clock, and dice and hand-over checks wait for their own animations.
- Better logs when the game engine fails, and an operator tool to correct past tournament records.
