# v0.69.0 — Chat over the table

Hidden chat now floats above everything on the board without getting in the way.

## Changed

- With the chat hidden, new messages float above prompts and windows, and clicks pass through them.
- Bomberman rooms are offered in Create room only with Experimental features on.

## Fixed

- A press the board was waiting on now shows "not taken" if Forge moves on without it.
- A room of a game other than Magic opens instead of saying "no such room".

## Fixes

- Every chat line's picture, overlay and name effect is checked in a real game.
- Steadier checks for the board, decks, drafts and the automated players.
- The tools that land and publish changes are stricter and explain their own errors.
- Better logs when a game server loses touch with its coordinator.
- Groundwork for updates that don't drop anyone's connection.
- More of the platform is shared between games, ready for the next one.
- Card art records for the cards new tests use.
- A plain-language guide to how the project works, and updated planning notes.
- The site's access settings are recorded beside the code.
- Dependency updates.
