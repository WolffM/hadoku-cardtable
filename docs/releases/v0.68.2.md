# v0.68.2 — Hits in order

Two timing fixes for slower screens, and the groundwork for the next game.

## Fixed

- On a busy computer, a chain of triggers no longer shows two of its hits landing at once: each waits for the one before it to be on screen.
- A question a die roll decides no longer appears a moment before the die lands on a slow screen.

## Fixes

- The parts every game shares are published, and a new game's starter is built on them.
- The tools that land and release changes work for any game, not only Cardtable.
- Steadier timing checks for triggers, dice and loops.
- The daily security report flags only what needs a look.
