# v0.80.0 — Steadier drafts and tables

Big draft rooms seat everyone, a lone drafter gets games, and a server or tab dropping out no longer stalls play.

## Changed

- Bots play is no longer offered in a draft room past eight seats, where the bots only draft.

## Fixed

- One game server dropping out no longer freezes the table or takes other servers' games down.
- A tab left open after its sign-in ended stops reconnecting and reloads signed in again.
- A draft with one person and Bots play off now plays its rounds against the bots.
- The ninth person and everyone after them is seated on joining a draft room, not left watching.
- A picked card no longer jumps back into the pack when someone else picks first.
- Events, tournaments, replays, cubes and room previews no longer stall when a name lookup hangs.
- A "choose a player" with no card to click (True-Name Nemesis entering, for one) asks you with the players to pick from. (@coffeetraveler)
- A spell you can cast more than one way says what each way costs: Baleful Mastery offers {3}{B} and {1}{B}. (@coffeetraveler)

## Fixes

- Steadier checks before an update ships, including a full draft tournament played by browsers.
- Art for the cards the new checks play.
- Better tools for reading what happened in a visit.
- Dependency updates.
- Planning notes.
