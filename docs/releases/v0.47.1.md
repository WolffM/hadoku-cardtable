# v0.47.1 — Replays show both players

Replays show both players' faces, and the servers that host games are steadier.

## Fixed

- Replays, including the one looping on the front page, now show both players' avatars. Games played before this update still show none.
- Replays of games played in testing rooms are no longer shown to everyone.

## Fixes

- A planned server restart no longer brings in the backup host or raises an alarm, and no new game starts on a server about to restart.
- Games run only on the servers cardtable asked for, in its preferred order, and cardtable checks every minute that its hosting is what it asked for.
- The backup host takes a game only when no game server can.
- A third game server, and the order the servers are used in.
- The daily health report lists every warning on its own line and counts traffic per site.
- Card art for new test scenarios and decks.
- Dependency updates.
- Notes for the server hosting.
