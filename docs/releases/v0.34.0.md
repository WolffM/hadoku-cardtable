# v0.34.0 — Card Table has a Discord

Card Table now has its own Discord server, and these notes are its first automatic post.

## New

- **A Discord button in the top bar**, next to the theme picker. It opens the invite, and joining
  makes you a Player. Patch notes land in #announcements, tournaments in #events, and
  #looking-for-game is for finding a table.
- **Patch notes post themselves.** Every release announces what changed here, the moment the main
  table updates.

## Changed

- **Smoother combat.** Big attacks and board wipes redraw far less of the page: Pyroclasm into a
  four-creature swing should no longer drop the frame rate the way it did.
- **Lighter effects.** A stack full of triggers no longer makes every card on it breathe its own
  shadow, mass deaths share one particle budget, and shrouded cards' mist no longer redraws them
  every frame.
- **Flyers hover steadily**, in step with each other, including in Firefox.

## Fixed

- **Rematch in a board-state room** replays the scripted board, instead of turning the game into a
  best-of-three and stopping at a sideboard step.
