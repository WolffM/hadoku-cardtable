## Size — checked before dispatch

**3 lanes**, disjoint files. The one shared contract is import lines: a lane that moves a symbol out of its file
rewrites every importer's import line in the same commit (codemod, committed). Those importer edits touch
import lines only, never bodies. **Long pole: L** (lobby.ts). Target 3 h, hard stop 4 h
(`~/.cache/cardtable-manager/w110-clock.txt`, written at dispatch).

## Settled — do not re-open in any lane

- **Pure moves and seams.** Non-test net ≤ 0, except a new platform interface a seam needs (named in the report).
  No behaviour change: every e2e spec and jvm suite passes unchanged, and the wire and `data-testid`s are frozen.
- **What "generic" means here** (the plan's rulings): rooms, membership, seats, ready per userId, leadership on
  Leave, watchers, chat, the room list, passwords, persistence through `@wolffm/rooms-server/store`, and the
  game-type registry are platform. Formats, decks, pods, draft deals, tables of 1v1 Magic, gauntlets and
  tournaments are Magic. Where a function mixes both, split it: a generic core that takes a game-type hook, and
  a Magic hook. Never an `if (gameType === 'draft')` left in a platform file.
- **Persisted records decode old files.** Room, draft and table records keep their decode-old tests on committed
  real fixtures. Any record shape that changes gets a decode-old case.
- **Layers:** `layers.json` and `baseline.json` are the manager's. platform→magic stays 0. Each lane ends with
  its files off the tangled list, and `node scripts/layers/baseline.ts` shows the count falling.
- Delete what you replace. No re-export shims. No wave numbers in source; no version edits; no AI attribution;
  never `/cutrelease` or `release.yml`; never `git stash`; never `pnpm install` in the worktree.
