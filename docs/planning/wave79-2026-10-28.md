## Shape: four single sessions, not a manager

Each lane below is one session in its own worktree (`.claude/worktrees/w79<x>`), doing its items in order and
landing itself with `scripts/land.sh`. The four own disjoint files and run at the same time. The protocol
below is written for a manager; in these sessions **you are the manager and the only lane** — do the work
yourself (no sub-agents unless your brief says so), and keep every rule about verification, landing, claims,
the clock and the closing note. Target 3 h, hard stop 4 h.

## Acceptance — the operator's sentence, not the lane's

Every item's FIRST commit is a scenario + a two-browser spec of the operator's exact sequence that is RED on
the base (per-frame evidence where the complaint is motion: a sampler of the card's box and attributes, the
way `e2e/nf-offer-gap.spec.ts` samples). The fix lands only with it green, in the same land. Where a cause
is unknown the first commit is telemetry, and the note says what it measured — no mechanism is named in this
brief as fact unless it says "measured". Claw proof with `-f video=true`; the note cites the run whose
`forge-e2e-videos-*` artifact holds both screens. Each item gets an `| AF??? |` ledger row in its landing
commit (`land.sh` numbers it) with the operator's words; only the operator writes ✅. A player-visible change
adds a `docs/releases/pending/2026-10-28-<slug>.md` in the same commit.
