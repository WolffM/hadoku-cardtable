## §A — The recovery path should not be the normal path

Wave 10 measured **serverPicks 90, serverResyncs 90**: every round is a `gap`
followed by a full snapshot. Root cause, confirmed: the engine bumps `seq` on
every state change, `runBots` takes six bot picks in one call, and the room
emits **one** update — so the client sees `seq` jump by ~7 and correctly asks
for a snapshot.

1. **The real problem is a category error, so fix that rather than the symptom.**
   `classifySeq` is built for a **delta** stream, where a missing seq means
   missing information. The room emits **full state**, which is self-contained —
   a jump is not a loss. Make the envelope say which it is, and let a full-state
   envelope be applied whatever its seq.
2. Do **not** fix it by emitting one update per bot pick. That trades a round
   trip for six, and the payloads are full state.
3. Do **not** fix it by loosening `classifySeq`. It is `@wolffm/rooms-protocol`'s
   and it is correct for the thing it models; the epoch check especially. If the
   contract genuinely needs a new verdict, that is a request to watchparty, not
   an edit here.
4. **Keep the epoch behaviour exactly.** `epoch-change` must still discard local
   state and refetch. That is P6's restart case and it is the one thing a
   full-state envelope does *not* make safe.
5. Done when: a full draft completes with **resyncs proportional to genuine
   gaps, not to rounds** — measured in `e2e/draft.spec.ts`'s summary, with the
   before (90/90) and after numbers both quoted; and `e2e/draft.spec.ts` passes
   unchanged otherwise.

## §B — Two humans play a match, end to end

The analogue of Wave 10 lane D, for play. **A measurement lane: it must not
change product code.**

1. Two independent browser contexts, two seats, one Forge match. Start it, play
   until at least one real prompt is answered by each side, and assert the board
   agrees with the server afterwards.
2. **Assert isolation over every envelope**, the way the draft e2e does: one
   seat's hand must never appear in the other's stream. The server-side control
   already proves this against raw Forge data; this proves it through a browser.
3. Exercise a **refresh mid-match** in one context. Wave 10 proved this for
   draft; play has reconnect grace from Wave 10 lane C and it is untested from a
   browser.
4. Needs a real Forge: gate on `CARDTABLE_FORGE_JAR` the way the server tests
   do, and say clearly in the closing note whether it ran or skipped.
5. Done when: two contexts play a real match with prompts answered from both
   sides and isolation asserted per envelope — or the closing note names exactly
   what stopped it. **A negative result here is worth more than a green skip.**

## §C — The refresh guard, and the trap that wastes an afternoon

1. **The `leaveRoom` guard is untested in reality.** Wave 10 found that on
   loopback the old socket closes **36 ms before** the new one joins, so the
   seat is held by the *reservation* and the guard never fires. For ~80 ms the
   other player sees the seat empty. Either make the guard cover the ordering
   that actually happens, or establish that the reservation is the real
   mechanism and the guard is redundant — **and say which**, because right now
   a unit test implies a protection that production does not exercise.
2. The ~80 ms empty-seat flicker is visible to the other player. Fix it or
   document it as acceptable; do not leave it unremarked.
3. **The dot-directory trap.** `/health` reports healthy while every page 404s
   when the server runs from a path containing a dot-segment — which is every
   agent worktree. express's `send` uses `dotfiles: 'ignore'`; `checkBasePath`
   uses `readFileSync` and does not care. Production is unaffected. **Make
   `/health` tell the truth**: if the bundle cannot actually be served, the
   probe must not say `healthy`. That is the sixth "green gate that does
   nothing" in this repo and the cheapest one to close.
4. Done when: the guard's status is settled and stated; the flicker is fixed or
   documented; and a server started from a dot-path reports **degraded**, with a
   test that fails if `/health` goes green while `sendFile` would 404.
