## The shared contract (pinned here, so no lane waits)

```ts
// apps/ui/src/rooms/game-setup.ts — platform. P creates it in its FIRST commit; X and B build against it.
export interface GameSetupProps {
  view: RoomView;            // the parsed public view (packages/shared)
  me: { userId: string; seat: number | null; isLeader: boolean };
  underway: boolean;         // the room's game has started
}
/** What a game type renders inside the platform room screen: its setup before the start, its game after. */
export interface GameRoomUi {
  setup?: (p: GameSetupProps) => ReactNode;   // Magic: deck chooser, format, mode. Absent: nothing above the seats.
  game: (p: GameSetupProps) => ReactNode;     // Magic: today's board/pod. Bomberman: B's <BundleSlot>.
}
export function registerGameRoomUi(gameType: string, ui: GameRoomUi): void;
export function gameRoomUiFor(gameType: string): GameRoomUi | null;
```

P may refine the shape in that first commit (it is the lane that knows `RoomTableScreen`), and it tells the
manager. The manager relays the final shape to X and B before they wire against it.

## §P — the platform room screen (long pole)

1. **Commit 1, the seam:** `rooms/game-setup.ts` (above). `RoomTableScreen` renders Magic's parts through
   `gameRoomUiFor(view.gameType)`, and Magic registers its UI for `constructed-1v1` and `draft`. Its DOM is

   and diff them.
2. **Commit 2, the move:** the platform half moves to `rooms/screen/` and Magic's to `screens/magic-setup/`.
   `ConstructedScreen.tsx` keeps what is genuinely the `#/play` screen (format and deck pick without a room) or is
   deleted if nothing is left.
   - The platform files import no Magic file. The ratchet proves it.
   - Hooks and state that are both (seat locks, `underway`, `dealing`) stay with the platform screen and reach Magic
     through `GameSetupProps`. Name each in the note.
3. **Prove it:**
   - `pnpm -r typecheck` and `pnpm run check` exit 0;
   - the DOM snapshots are identical;
   - ×1 on claws: every spec from `grep -rlE "room|seat|ready|spectat|password|leader|join" e2e/*.spec.ts`, split
     under the 45-minute cap, ≤ 3 in flight. This is a big set; the manager schedules it against the other lanes'
