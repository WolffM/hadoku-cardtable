## The shared contract (pinned here, so no lane waits)

```ts
// apps/ui/src/rooms/game-setup.ts — platform. P creates it in its FIRST commit; X and B build against it.
export interface GameSetupProps {
  view: RoomView;            // the parsed public view (packages/shared)
  me: { userId: string; seat: number | null; isLeader: boolean };
  underway: boolean;         // the room's game has started
}
/** What a game type renders inside the platform room screen: its setup before the start, its game after. */
export interface GameRoomUi {
  setup?: (p: GameSetupProps) => ReactNode;   // Magic: deck chooser, format, mode. Absent: nothing above the seats.
  game: (p: GameSetupProps) => ReactNode;     // Magic: today's board/pod. Bomberman: B's <BundleSlot>.
}
export function registerGameRoomUi(gameType: string, ui: GameRoomUi): void;
export function gameRoomUiFor(gameType: string): GameRoomUi | null;
```

P may refine the shape in that first commit (it is the lane that knows `RoomTableScreen`), and it tells the
manager. The manager relays the final shape to X and B before they wire against it.
