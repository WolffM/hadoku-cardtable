## Settled — do not re-open in any lane (operator, 2026-11-06)

1. **Licence: "whatever is least restrictive."** The operator's words: *"i dont understand much about how
   licenses work, we're not making any money with cardtable so i dont really give a shit what license it has.
   whatever is least restrictive."*
   - MIT is the default.
   - GPL-3.0-or-later stays only where Forge requires it: the Forge submodule, Magic-layer code (anything
     transcribed from Forge, the Java bridge), and any package that still contains such code.
   - This is D26, and lane A writes it.
   - Every commit on main is the operator's own or their CI bot's, so this code is theirs to relicense. Code
     derived from Forge never is.
2. **The next game could be anything.** *"you should assume the game client could be literally anything. might
   be a rust client package like bomberman."* So there is no card kit. The board and everything card-shaped
   belong to the Magic layer.
3. **Magic gets its own layer, cleanly.** *"it would be nice to seperate all the mtg logic to it's own layer so
   the seperation is clean."*
   - This wave makes that layer exist in a map, enforced by a test.
   - The physical move to `games/magic/` is a later wave, because the deploy tree keeps a gitignored 184 MB card
     corpus inside `packages/carddata/data/`. Moving the package needs a host step of its own.
4. **The streamed desktop stays.** The operator asked why it would go: *"isn't it just another parallel
   execution lane?"* It is.
   - `stream/alloc.ts` and `stream/index.ts` are game-agnostic; only `scripts/stream/container.sh` names Forge.
   - So it is a platform runtime. Nothing deletes it, and lane C gates it like every other socket.
5. **`room-ask` stays** until phase 5 decides whether the match shell adopts it.
6. **The DOM contract is frozen.** No `data-testid`, `data-*` or class renames.
7. **Consolidation lands net-negative.** Each lane's non-test diff is ≤ 0 lines, with a "made dead / deleted"
   line in its note. A is exempt because it adds test infrastructure, but its product-code diff is 0.

## §A — Layer fence and the licence ruling (plan phase 1)

The repo lands 50–230 commits a day, and it added 13k lines in the 33 hours before this wave. So the fence goes
up before any extraction. After it, a new import from generic code into Magic code is a visible decision
instead of an accident.

1. **The docs commit comes first.**
   - `docs/DECISIONS.md`: add **D26 — MIT by default; GPL only where Forge requires it** (settled, 2026-11-06,
     operator), quoting settled item 1 above. It says:
     - New platform packages are MIT from creation.
     - Existing code is relicensed when it moves into a package whose files are all platform.
     - GPL stays on `forge/`, on Magic-layer files, and on any package that still holds one. Today those are
       `apps/server`, `apps/ui`, `apps/agent`, `packages/shared`, `forge-wire`, `carddata`, `deck` and `draft`.
     - It amends D16: room-ask was the one MIT carve-out, and D26 makes MIT the default. Add a one-line pointer
       under D16.
   - `docs/LICENSING.md`: a short section on the split. Point at D26, and at `scripts/layers/layers.json` as the
     record of which file is in which layer.
   - `NOTICE.md`, and the `AGENTS.md` line that says GPL-3.0-or-later applies to the whole repo: reword both to
     describe the split. Do not touch Forge's per-file headers or the fonts' licence files.
2. **The map, `scripts/layers/layers.json`.** It has four layers:
   - `platform`: MIT, and may import platform only.
   - `magic`: GPL, and may import platform, magic and tangled.
   - `tangled`: GPL; a generic mechanism with Magic woven in. May import anything except site.
   - `site`: GPL for now. This is the composition root (`apps/server/src/index.ts`, `apps/ui/src/App.tsx`, the
     front page, branding), and it may import anything.

   **Paths** are globs, and the most specific match wins. `tangled` is different: it is an explicit file list,
   never a glob, and it may only shrink, so a new file can never be tangled.

   **Classification rules, in order:**
   1. These are magic, because there is no card kit (settled 2):
      - `packages/{forge-wire,carddata,deck,draft}/**`
      - `apps/server/src/**/*.java`
      - `apps/ui/src/symbols/**`, `apps/ui/src/play/**`, `apps/ui/src/draft/**`, `apps/ui/src/deck/**`
      - every file transcribed from Forge, by name. `visibility.ts`, `fold.ts` and `prompts/rules.ts` are known.
        Search for more with `git grep -l -i -E "transcrib|copied from forge|forge's [a-z]+\.java" -- apps packages`,
        and read each hit.
   2. These are platform:
      - `packages/{room-ask,room-store}/**`
      - `apps/server/src/stream/**`
      - `apps/server/src/{edge-auth,gate,telemetry,capacity,state-dir}.ts`
   3. Classify everything else per file, by what it imports and what it is for. Use the plan's "Where the code
      sits today" table as the guide. A file that holds a generic mechanism plus Magic content goes in `tangled`.
   4. Test files and fixtures are not classified and not counted. That means `*.test.ts(x)`, `*.jvm.test.ts` and
      `__tests__/**`. Test support that lives under a non-test name goes on its own `test-support` list.
3. **The ratchet, `scripts/layers/ratchet.test.ts`.** The root vitest config already includes
   `scripts/**/*.test.ts`, so `pnpm run check` runs it.
   - **Coverage.** Collect every tracked `.ts`/`.tsx` source file under `apps/*/src` and `packages/*/src` with
     `git ls-files`. Every one must have a layer, and every file the map lists must exist.
   - **Imports.** Read imports, re-exports and dynamic imports with TypeScript's `ts.preProcessFile`. Resolve a
     relative specifier to its file, and `@hadoku/<pkg>` to that package's layer. External packages, `@wolffm/*`
     included, are not counted.
   - **Counting.** Count every edge in a direction the map forbids, per (from, to) pair, and compare with
     `scripts/layers/baseline.json`.
     - A count that rises fails. It prints one line per new edge, `file:line imports 'spec' (platform → magic)`,
       and three ways out:
       1. move the Magic part next to its Magic peers;
       2. classify the importing file as Magic in `layers.json`, if that is what it is;
       3. put the generic part in a platform file.
     - A count that falls passes, and prints the one command that writes the new baseline
       (`node scripts/layers/baseline.ts`).
   - **Licences.** Every `apps/*/package.json` and `packages/*/package.json` whose source files are all `platform`
     declares `MIT`, and every other one declares `GPL-3.0-or-later`. A mismatch fails, unless the package is on
     a `pendingLicence` list in `baseline.json`, which may only shrink. At dispatch the one expected entry is
     `room-store`; B's relicense empties the list.
   - **Provenance.** No `platform` file carries a GPL header (`SPDX-License-Identifier: GPL…` or "GNU General
     Public License").
4. **Prove it bites.** Add `import '@hadoku/forge-wire';` to a platform file and run the test: it fails and names
   the file and line. Revert it, and it passes. Both outputs go in the closing note.
5. **A "Layer fence" paragraph in `AGENTS.md`**, three sentences: what the test checks, where the map is, and what
   to do when it fails.
6. **Done when:**
   - `pnpm run check` is green on the landed sha, and the ratchet is in its output;
   - the closing note has step 4's two runs;
   - the note gives non-test lines per layer: platform, magic, tangled, site and test support;
   - D26 is on main.
