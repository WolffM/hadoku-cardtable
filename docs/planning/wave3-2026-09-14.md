## §A — The draft engine and the wire schema

The missing middle of PR-2. Transport-free: no sockets, no `rooms-server`, no
`io`. A reducer — state plus an action gives new state plus events.

1. Depend on **`@wolffm/rooms-protocol@0.38.110`** and nothing else from that
   family. Importing `@wolffm/rooms-server` or `socket.io` fails the lane. Read
   `seats.d.ts` before writing a line: `SeatId` **is** the ordering, seats are
   sticky across reconnect, `SeatOccupant` covers `kind:'bot'`, `padWithBots`
   gives deterministic positional `bot:<n>` ids, humans evict bots.
2. Pack building from a cube pool plus a recipe (both already parse — Wave 2
   lane A). Shuffle, deal `NumPacks × NumPlayers`, honour `Singleton`. A
   **seeded** RNG you own; `Math.random` fails the lane, because replay is the
   entire test strategy.
3. The pick/pass loop: direction alternates by pack round (left, right, left),
   a pick is validated against the actual pack, out-of-turn and duplicate picks
   are **rejected as values, not thrown**, and the round advances when every
   pack is empty.
4. The heuristic bot, deterministic under the seed, picking for every
   `kind:'bot'` seat.
5. The Zod schema in `packages/shared`. **Write it against the five committed
   fixtures** — `apps/ui/src/draft/fixtures/*.json`. Per Wave 2's plan a
   mismatch is a UI bug, but that ruling was made when the schema was going to
   come first; it did not. **If a fixture cannot be made to validate without
   distorting the schema, stop and report it** rather than bending either side.
6. Hidden information is enforced *here*, not just asserted in the UI: a seat's
   payload carries its own pack and pool and nothing of anyone else's.
   **Build the payloads through a shape `emitPerRecipient` can drive**: its
   `build` callback receives a `ClientMeta`, and the seat comes from
   `seatOf(room.seats, client.participantId)`. Wiring is Wave 4's, but a
   payload builder that can only produce all seats at once cannot be adapted.
7. **Stamp an `epoch`, not just a `seq`.** ⚠️ **The tracker found this while
   reading `0.38.110` as its first consumer, and it is a real gap in the
   envelope Wave 2 committed.** All five fixtures carry `seq` and **no
   `epoch`** — so as written they cannot use `classifySeq` at all. Per
   `rooms-protocol/resync.d.ts`, `SeqCursor` is `{ epoch, seq }`, and the epoch
   is what separates "I missed events" from "the server restarted and started
   counting again" — the two need **opposite** responses (catch up vs. discard
   and refetch), and it is exactly P6's restart case. Their own header is
   explicit that `lastEventSeq` is stamped only on watchparty's playback control
   events, so **an app that wants gap detection stamps its own `SeqCursor`**.
   That is us. Add `epoch` to the envelope, change the five fixtures to match —
   **this is the one sanctioned edit to `apps/ui/src/draft/fixtures/*.json`**,
   and lane E must be told the shape moved.
8. Done when: an 8-seat, 3-pack draft runs to completion in a test; **the same
   seed twice produces a byte-identical pick log**; an out-of-turn pick is
   rejected without throwing; **all five committed fixtures validate under the
   schema** (this is Wave 2's outstanding B↔C check, now a done-when); and a
   test asserts over a **whole serialised payload** that no seat's view contains
   another seat's cards; **and every fixture carries an `epoch`**.

   least one written deck is byte-compared against a Forge-authored `.dck` of
   the same content. Read `forge/` read-only for that comparison.

   exist, and `rooms-protocol/resync.ts` ships the seq-gap and
   identity-reassert contract we asked for in place of `rooms-client`. Delete
   any remaining ask they have already satisfied. **Verify each deletion
   against the published package**, not against their release notes.
2. Add our answer on **W3 / their §3.2** — the seat hole. The operator has
   settled it: **we want reservation-with-TTL, not the socket Set.** The
   argument, and the two shape requests that go with it, are in the operator's
   note; carry them faithfully:
   - The socket Set only covers refresh-with-overlap. A network blip, a
     suspend, or a backgrounded tab closes the socket with no overlap, the set
     empties, and a bounded pod loses the seat. Reservation covers those too.
   - On a **server restart** every socket drops at once, so a socket Set is
     empty for all eight seats simultaneously and cannot help. That is exactly
     P6's requirement.
   - Ask for a **per-room configurable TTL** (they want short, we want minutes),
     and for a reservation that can **survive an explicit leave**, because a
     drafter who quits should be botted-and-reclaimable rather than freeing the
     seat. Offer the fallback: if that is awkward, we will bot it our side.

5. Done when: the branch is pushed with an upstream set; every ask in it is
