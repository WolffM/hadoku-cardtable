## Wire contract — A creates `packages/shared/src/pool.ts`, verbatim

```ts
import { z } from 'zod';
import { DraftCardSchema } from './draft.ts';

export const PoolSourceSchema = z.discriminatedUnion('kind', [
  z.strictObject({ kind: z.literal('cube'), cubeId: z.string().min(1) }),
  z.strictObject({ kind: z.literal('set'), code: z.string().min(1), style: z.enum(['realistic', 'set-cube']) }),
]);
export type PoolSource = z.infer<typeof PoolSourceSchema>;

export const DraftPlanSchema = z.strictObject({
  rounds: z.tuple([PoolSourceSchema, PoolSourceSchema, PoolSourceSchema]),
});
export type DraftPlan = z.infer<typeof DraftPlanSchema>;

export const PoolVerdictSchema = z.discriminatedUnion('ok', [
  z.strictObject({ ok: z.literal(true), cards: z.number().int().nonnegative() }),
  z.strictObject({ ok: z.literal(false), unplayable: z.array(z.string()), missingText: z.array(z.string()) }),
]);
export type PoolVerdict = z.infer<typeof PoolVerdictSchema>;

export const CubeSummarySchema = z.strictObject({
  id: z.string(),                       // shortlist: file stem; imported: 'cc-' + Cube Cobra short id
  name: z.string(),
  size: z.number().int().nonnegative(),
  origin: z.enum(['shortlist', 'cubecobra']),
  cubeCobraId: z.string().nullable(),
  importedBy: z.string().nullable(),    // friend id; null for shortlist
  importedAt: z.string().nullable(),    // ISO
  refreshedAt: z.string().nullable(),   // ISO
  verdict: PoolVerdictSchema.nullable(),// null = not yet checked at this Forge pin
});
export type CubeSummary = z.infer<typeof CubeSummarySchema>;

export const ImportCubeBodySchema = z.strictObject({ link: z.string().min(1).max(300) });
export const SetDraftPlanBodySchema = z.strictObject({ plan: DraftPlanSchema });
```

A exports these from `packages/shared/src/index.ts`. **A's first commit is this
file and that export line, alone. The manager lands it at once** so B and C
rebase onto real types.

`PodView` (`packages/shared/src/pod.ts`, A's) gains
`plan: DraftPlan, planName: string, verdict: PoolVerdict | null`. `planName` is
the display name of round 1's source. `verdict` is null while a check is
running.

**Routes**

- **A**: `PUT /api/rooms/:id/pod/plan` with `SetDraftPlanBody`. Leader only,
  lobby phase only.
  - It runs the verdict first.
  - Refused: 409 `{ verdict }`, and the plan is unchanged.
  - Accepted: 200, and the plan is broadcast on the room like any pod change.
  - A source with `kind: 'set'` is refused 400 this wave.
- **C**: these routes, mounted by A's `index.ts` through C's `attachCubeRoutes`:
  - `GET /api/pools/cubes` → `CubeSummary[]`, imported first (newest first),
    then the shortlist in file order.
  - `POST /api/pools/cubes/import` `ImportCubeBody` → 201 `CubeSummary`, or
    400 `{ error }` for a bad link or a failed fetch.
  - `POST /api/pools/cubes/:id/refresh` → 200 `CubeSummary`.
  - `DELETE /api/pools/cubes/:id` → 204. 403 unless the caller is
    `importedBy`; 400 for a shortlist cube.

**Server module contracts (TypeScript, not wire)**

```ts
// C — apps/server/src/pools/cubes.ts
export interface CubeStore {
  list(): CubeSummary[];
  cards(id: string): readonly DraftCard[] | null;
  importLink(link: string, by: string): Promise<CubeSummary>;
  refresh(id: string, by: string): Promise<CubeSummary>;
  remove(id: string, by: string): void;                 // throws a typed refusal; never a silent no-op
  setVerdict(id: string, verdict: PoolVerdict): void;
}
export function createCubeStore(opts: {
  shortlistDir: string; importDir: string; catalog: CardCatalog;
  fetchJson?: (url: string) => Promise<unknown>;        // injectable; default global fetch
}): CubeStore;
export function attachCubeRoutes(router: Router /* express, as http/rooms.ts */, deps: { store: CubeStore; check: (cards: readonly DraftCard[]) => Promise<PoolVerdict> }): void;

// C — apps/server/src/pools/catalog.ts
export interface CardCatalog { byName(name: string): DraftCard | null }
export function loadCardCatalog(path: string): CardCatalog;   // verdict-style: a missing file is a reported fault, not a throw at boot

// D — apps/server/src/pools/forge.ts
export interface ForgePools {
  check(names: readonly string[]): Promise<string[]>;   // names Forge's card DB does not know
  sets(): Promise<{ code: string; name: string; date: string; type: string }[]>;
  setCards(code: string): Promise<string[]>;            // non-basic unique names
  boosters(code: string, count: number, seed: string): Promise<{ name: string; set: string; collectorNumber: string }[][]>;
  close(): Promise<void>;
}
export function createForgePools(config: /* host.ts's JVM config type */ unknown): ForgePools;
```

A's verdict for a cube source:

- `forge.check` over the cube's names gives `unplayable`.
- A card the store could not resolve to text gives `missingText`.
- The result is cached per (cubeId, Forge pin) and written back with
  `store.setVerdict`.
