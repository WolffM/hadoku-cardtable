sequence (pointer steps included, both screens recorded) that is RED on the base; the fix lands only
with it green, in the same land. A brief names NO mechanism without a measurement — where the cause is
unknown, the lane's first commit measures and the note says what it measured. Visual items (B, C) are
also seen drawn headless (memory `visual-fixes-need-a-browser-check`): the note carries a before/after
screenshot path under the gitignored `docs/handoff/`. The claw proof is dispatched with
`-f video=true`, and the note cites the run whose `forge-e2e-videos-*` artifact holds both screens.
Ledger rows read `landed <sha>`; only the operator writes ✅.
