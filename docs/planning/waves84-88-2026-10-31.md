## Interfaces fixed up front

**w84a → w84b** (`packages/draft/src/pairing.ts`):
- `roundsFor(n)` returns `min(3, ceil(log2 n))`, and 0 for n ≤ 1.
- `pairRound` pairs a flat list of entrant ids across the whole field, ignoring pods, with the same rules
  as today: no rematch while one is avoidable, and byes rotate.
- `rankStandings` gives a total order. It extends today's keys (match points, OMW%, GW%, OGW% with the 33%
  floor, median game length) with **head-to-head**, where the tied players met, then a **seeded draw**
  (a hash of the tournament id and the player id), so `decidedBy` always names a key and no two rows share
  a rank.
- w84a publishes the exact signatures in its first commit and tells w84b.

**w85b → w85a:**
- `GET /api/events` returns each event with its room's live state (from the room, not a copy).
- Attached forms: `POST /api/events/forms {formId}` validates the form through Rally's summary and accepts
  only `event-signup@1`. `GET /api/events/forms` returns the open attached forms, each with Rally's summary.
- w85b publishes the shapes in `packages/shared` first and tells w85a.
