## Settled — do not re-open in any lane

- **Gauntlet flips a coin for every game** (operator 2026-10-26, AF407). The loser-chooses rule (AF172,
  `e99df1bf`) is for a SERIES (Bo3, pods), never for Gauntlet games.
- **Gauntlet's last deck is picked by hand**, like the others (AF402): "it gives the opponent a chance to
  see it". No auto-pick of a sole remaining deck.
- **"All" is a macro, not a mode** (AF404): one press draws every legal attacker's arrow, exactly as if each
  had been dragged; any of them can then be removed or re-aimed before Done.
- **A fetchland is not a mana ability** (AF400): it cannot be cracked inside a payment. The fix is that a
  payment the seat can neither pay nor decline never sits open, not a rules change.
- No explanatory UI text (memory `no-explanatory-ui-text`). Theme tokens only.
- **The mistake bubble** (AF409, approved 2026-10-26): the seat's own avatar says the line, on the seat's
  own screen only (never the opponent, never a watcher); a Settings → Game checkbox "Say my mistakes",
  default on; off = today's card shake only. Lines, exactly: second land → "I already played a land this
  turn."; without priority → "I have to wait for priority."; summoning-sick attacker → **"Give that creature
  a turn to get ready."** (the operator's wording, replacing the preview's); not enough mana → "I don't have
  enough mana for that." ONLY where the cause is certain (the server's own auto-cancel of an unpayable
  cast). **A line is said only when the cause is certain** — an ambiguous refusal says nothing (keeps the
  shake). Look: the preview's "Speech + card" variant (bubble with tail from the avatar + the existing
  refused-card shake) unless the operator picks another before D starts.
