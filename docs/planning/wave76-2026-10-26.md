## Settled — do not re-open in any lane

- **Gauntlet flips a coin for every game** (operator 2026-10-26, AF407). The loser-chooses rule (AF172,
  `e99df1bf`) is for a SERIES (Bo3, pods), never for Gauntlet games.
- **Gauntlet's last deck is picked by hand**, like the others (AF402): "it gives the opponent a chance to
  see it". No auto-pick of a sole remaining deck.
- **"All" is a macro, not a mode** (AF404): one press draws every legal attacker's arrow, exactly as if each
  had been dragged; any of them can then be removed or re-aimed before Done.
- **AF410: a disconnected seat is released after 30 s** when no match is live at its table (operator
  2026-10-26, "30s seat release is fine"). A reload inside the 30 s keeps it.
- **No question reaches a seat that it cannot answer** (AF412, operator 2026-10-26: "how can we unify the
  behavior better so that we don't soft lock?" — "yes do both"). Lane A builds ONE rule for every ask, not
  per card; Punishing Fire and Elephant Grass are its first tests, not its scope.
- **A fetchland is not a mana ability** (AF400; CR 605.1a, 508.1g–h): it cannot be cracked inside a payment,
  and we do not bend the rules. What we owe the player is the window BEFORE the payment where cracking it is
  legal (beginning of combat / upkeep), and a way out of a payment they cannot make.
- No explanatory UI text (memory `no-explanatory-ui-text`). Theme tokens only.
- **The mistake bubble** (AF409, approved 2026-10-26): the seat's own avatar says the line, on the seat's
  own screen only (never the opponent, never a watcher); a Settings → Game checkbox "Say my mistakes",
  default on; off = today's card shake only. Lines, exactly: second land → "I already played a land this
  turn."; without priority → "I have to wait for priority."; summoning-sick attacker → **"Give that creature
  a turn to get ready."** (the operator's wording, replacing the preview's); not enough mana → "I don't have
  enough mana for that." ONLY where the cause is certain (the server's own auto-cancel of an unpayable
  cast). **A line is said only when the cause is certain** — an ambiguous refusal says nothing (keeps the
  shake). Look: the preview's "Speech + card" variant (bubble with tail from the avatar + the existing
  refused-card shake) unless the operator picks another before D starts.

## §A — every question can be answered (AF412, proven by AF398 and AF400), and outlines (AF401, AF403)

The operator, 2026-10-26: *"i'm tired of running into cards that just straight up don't work with our UI.
how can we unify the behavior better so that we don't soft lock?"* Every stall so far was found in play and
fixed alone (AF1, AF2, AF68, AF333, AF398, AF400). This lane replaces that with one rule in one place on the
server's ask path: **no ask reaches a seat unless the seat can answer it with what our UI offers.** Evidence for
the first two: `m-6eed2f853a79` frames `Punishing Fire (2) - \n\nPay Mana Cost: {R}` (and `(4)`) with no red
source, and `Elephant Grass\n\nPay Mana Cost: {G}`, which the operator could neither pay nor leave. AF68
(Chain Lightning, lane INT, pin e27f6eb4), AF2 (Fire-Lit Thicket) and `unparsed.ts` are three partial versions
of this rule: fold them into it, do not add a fourth beside them (memory `waves-must-delete-what-they-replace`).
Lane A additionally owns `apps/server/src/play/match.ts`, `apps/server/src/play/unparsed.ts` (+ tests) for this.

1. **Measure first:** list every ask method and input kind the bridge forwards (`PlayBridge.java`'s seat
   controller and GUI; the server's ask path in `match.ts` / `auto.ts` / `unparsed.ts`), and for each: what
   "answerable" means and what Forge's legal decline is (a payment: can any available source pay it, is
   Cancel allowed; a pick: enough legal options for its minimum; a confirm: both buttons present). The table
   goes in a comment beside the rule and in the note.
2. **RED first:** a jvm scenario per proving case — Punishing Fire in the graveyard, the opponent gains life,
   no red untapped; Elephant Grass's payment with only a fetchland and a tapped land — each asserting the seat
   is never handed the ask and the game moves on (Punishing Fire stays in the graveyard; the unpaid branch
   happens as the card says). Plus one case of a DIFFERENT shape from the table (e.g. a mandatory pick with
   fewer legal options than its minimum), so the rule is shown not to be about payments only.
3. **The rule:** one function on the ask path. An unanswerable OPTIONAL ask is declined by the server; an
   unanswerable MANDATORY ask gets Forge's own legal answer (the unpaid branch, the empty pick Forge accepts).
   Both log one event, `ask-unanswerable` {card, method, why}. An ask the rule cannot classify logs
   `ask-unclassified` and is forwarded as today — never dropped.
4. **The fetchland window (operator 2026-10-26: "can we let people use fetchlands so they can pay for stuff
   like that?"):** the rules forbid cracking a fetch inside a payment, so give the window before it. When the
   seat is about to declare attackers and an attack cost applies to it (Elephant Grass, Ghostly Prison,
   Propaganda — read Forge's attack-cost statics, never a card list), and the seat holds an untapped
   permanent with a non-mana ability that can fetch or make a mana source (a fetchland), the auto-pass does
   NOT skip its Beginning of Combat priority (`auto.ts`, the same stop machinery AF388 used). The same for an
   upkeep cost (cumulative upkeep, echo) and the upkeep step. RED: a scenario with Elephant Grass across the
   table, a fetchland and too few untapped lands to pay — the seat gets Beginning of Combat priority, cracks
   the fetch, then declares and pays. And an attack payment the seat still cannot make unwinds the
   declaration (Forge's decline = those attackers do not attack) instead of sitting open — that is rule 3.
5. **AF401:** Infernal Tutor's hellbent clause lit the orange rim with a full hand. Third report of this rim
   (AF214, AF300 — read AF300's `ConditionsOn.counts` fix). RED: `condition-met.jvm.test.ts` case with
   Infernal Tutor and cards in hand → `conditionMet` false; empty hand → true. Survey the other hellbent /
   threshold-style conditions the same fix touches and list them in the note.
6. **AF403:** Calibrated Blast cast twice in `m-bafaa3d3238f` (normal and flashback); "nothing revealed".
   Measure first: what Forge sends for "reveal until nonland" (a `reveal` call, a log line, nothing) and what
   our client draws for it. Fix in the bridge if it drops the reveal; if the fix is UI, stop and report
   (C owns no reveal file either — it goes to the next wave).
7. Done when: each new jvm test fails on the base and passes landed (named in the note with counts), the
