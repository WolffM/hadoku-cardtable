## Settled — do not re-open in any lane

- **Room logic is identical across apps;** only CSS and UI differ (operator; memory `shared-room-logic-with-watchparty`).
- **Seats:** a spectator can never take an active player's place. Nobody can unseat someone else. New members
  auto-seat, and the spectators row replaces Stand (2026-11-02, `seats-and-watchers-contract`).
- **Ready is per unique userId,** not per socket or connection (plan 742).
- **The leader never moves on a disconnect.** It moves only when the leader presses Leave, to the earliest-joined member
  (R16, cardtable `room/lobby.ts:3545`). A "promote" button can come later (plan 743).
- **Joining a room means joining its chat** (plan 744).
- **Licence:** watchparty's room packages are MIT. Cardtable's `GameTypeSpec` type lives in a platform (MIT) file; the
  Magic spec values live in a Magic file. The layer ratchet must pass.
- Nothing in this wave changes what a cardtable player sees. Watchparty's chat changes are fixes the plan names: the
  password-room chat hole, the two-minute chat wipe, and the deploy hold (plan 393–395).
