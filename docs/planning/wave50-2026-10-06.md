## Settled — do not re-open

- **Server-hosted.** The cardtable server serves the takes from its own data dir; no CDN, no credential. Allowed:
  the image-host rule was repealed (D18) and audio was never under it. **Audio bytes never enter the repo**
  and never the UI bundle. `.gitignore` refuses `*.jpg`/`*.png` today but NOT audio: lane S adds `*.ogg`, `*.wav`,
  `*.mp3`, `*.flac` (checked by the tracker, 2026-10-06).
- **Storage:** `CARDTABLE_SOUNDS_DIR`, default `resolve(CONFIG.logDir, '../data/sounds')` — the same pattern as
  `CARDTABLE_ROOMS_DIR` (`apps/server/src/index.ts:299`), which in production resolves under the deploy tree's
  gitignored `apps/server/data/`. Layout: `catalogue.json`, `takes/<folder>/<file>.ogg`, `assignments.json`.
  Writes are atomic (temp file + rename). A missing dir means an empty catalogue, never a crash.
- **The gate.** Reads are friend tier (the game will play these to every player later); every WRITE is admin
  tier: `rankOf(tierOf(req)) >= rankOf('admin')` from `apps/server/src/edge-auth.ts` (the edge-stamped, sanitized
  tier — never a header the client controls). The builder screen shows only when the server says `canEdit`.
- **The API contract** (both lanes code to it from t=0; S owns the schema file):
  - `GET /api/sounds/catalogue` → `{ takes: SoundTake[] }`, where `SoundTake` = `{ file, sound, name, group,
    section, label, seconds, prompt }`. `file` matches `^[a-z0-9][a-z0-9.\-]*/take-[a-z0-9-]+\.ogg$`. `section` is
    one of `Library | Land types | Moments | Colour sounds`.
  - `GET /api/sounds/takes/:folder/:file` → the Opus file, `audio/ogg`, long immutable cache. Path segments are
    validated against the same pattern and resolved inside the takes dir. No traversal, ever.
  - `GET /api/sounds/assignments` → `{ cells: Record<CellId, string[]>, canEdit: boolean }`.
  - `PUT /api/sounds/assignments/:cell` with `{ files: string[] }` → admin only (403 otherwise). Every file must
    be in the catalogue, at most 32 per cell; replies with the saved cell.
  - `CellId` = `<row>|<col>`: a colour-identity row (`W U B R G WU UB BR RG GW WB UR BG RW GU GWU WUB UBR BRG RGW
    WBG URW BGU RWB GUR WUBRG C`) × `spell | creature | land | artifact | artifact-creature`, or an event row × `play`
    (`m-draw m-shuffle m-tapcard m-resolve m-attack m-block m-damage m-damage-player m-dies m-phase m-turn m-win
    m-lose`). These row and column lists, with display names, families and colour pips, live in ONE shared constant
    beside the schemas.
- **The builder** is a React port of the artifact the operator already approved (its source:
  `docs/handoff/snapshot/builder.html`). Keep its behaviour, which the operator tested and corrected:
  - the bin holds only the keepers, as dense pill rows, one row per sound;
  - click a pill to play it and pick it up, then click a cell to add it; dragging also works; Esc puts it down;
  - **no "holding" banner** (the operator: *"this notification is annoying, it shifted the page, just get rid of it"*);
  - a cell holds many takes; its ▶ plays one at random and never the same one twice in a row;
  - a placed pill plays on click, ✕ removes it, and dragging moves it between cells;
  - mono identities' Land cell is labelled with its basic land (Plains, Island, Swamp, Mountain, Forest);
  - "Play a sample turn" sequences the assignments with overlap (an 8-voice pool) on the artifact's timeline;
  - no explanatory text on the page beyond its title.
- **The seed.** The operator's assignments so far (12 cells) and the 140 keeper takes are imported by the
  TRACKER after deploy, into production's data dir, with the import tool this wave builds. Lanes never touch
  production's data dir. Tests use small synthetic fixtures, never the snapshot.
- **Licence.** Takes generated by Stable Audio Open ship with the attribution its licence asks for: `NOTICE.md`
  carries "This Stability AI Model is licensed under the Stability AI Community License, Copyright © Stability AI
  Ltd. All Rights Reserved" and "Powered by Stability AI". The hand-rolled victory and defeat takes are ours.
- No version bumps, no ledger edits, no pushes. Land on `w50`, run the full gate (w49's wave file, Settled), and
  report READY; the tracker integrates w49 then w50 and pushes once.

## §S — server, storage, import

1. `packages/shared/src/sounds.ts`:
   - the schemas;
   - the `CellId` grammar;
   - the shared row/column/event constant, with display names, families, colour pips and land names.

   Strict, with unit tests for a valid and an invalid id/file each.
2. `apps/server/src/http/sounds.ts`: the four routes. Tests (express + headers, as `rooms.test.ts` does):
   - friend can read and cannot write (403);
   - admin can write;
   - an unknown file or a malformed cell → 400;
   - traversal attempts (`..`, encoded slashes, absolute paths) → 400 and never a read outside the dir;
   - a missing data dir → empty catalogue;
   - atomic write survives a crash mid-write (temp file left, real file intact);
   - `canEdit` true only for admin.
3. Mount it in `index.ts` behind the same floor as `/api/rooms`.
4. `scripts/sfx/import.py --from <finished dir> --seed <assignments.json> --to <sounds dir> [--force]`:
   - builds `catalogue.json` (labels, groups and sections exactly as the artifact's staging did:
     `docs/handoff/snapshot/stage-builder.py`);
   - copies the `.ogg` files;
   - writes `assignments.json` only if absent, unless `--force`;
   - prints counts.

   Run it against the snapshot into a temp dir and record the counts. Expect 140 takes and 12 cells.
5. `NOTICE.md`: the Stability attribution.
6. **Done when:**
   - `pnpm run check` exits 0;
   - the route tests are green;
   - the mutation: drop the admin check → the "friend cannot write" test FAILS; restore it → passes, with counts;
   - the import's counts are in `evidence/S/README.md`.

## §U — the builder screen

1. `#/sounds` → `SoundBuilder`, from the snapshot's `builder.html`, ported to React and the app's own CSS tokens.
   Behaviour is as in Settled.
   - If `canEdit` is false, render nothing useful; the route is admin-only and no link points at it for others.
   - Saves are per cell (PUT). A failed save shows the cell as unsaved, without text banners.
2. `builderClient.ts`: fetch, parse with the shared schemas, and a small audio pool:
   - 8 voices;
   - each take fetched once, then cached as an object URL;
   - a random pick per cell that never repeats back to back.
3. Unit tests (jsdom):
   - click pill → click cell sends one PUT with the cell's new list;
   - drag between cells sends two PUTs (source, then target);
   - ✕ removes the take;
   - the random pick never repeats when a cell has more than one take;
   - with `canEdit` false nothing is editable.
4. `e2e/w50-sound-builder.spec.ts`, against a stack whose sounds dir holds a tiny synthetic catalogue (2–3 silent
   Opus files the spec generates with `ffmpeg`, never committed). The stack needs an admin tier: the server's
   bare-local dev tier is `CARDTABLE_DEV_TIER` (`apps/server/src/config.ts:80`); start the spec's stack with it set to
   `admin` for the admin half and `friend` for the other. If the harness cannot pass it, say so and test the gate at
   the server level only.
   - Admin can place a take and reload to find it saved.
   - A friend gets no editor.
5. **Done when:**
   - `pnpm run check` exits 0;
   - the spec is green 3 runs in a row with 0 SKIPPED (or the gate gap is stated);
   - screenshots of the builder at desktop and phone width are viewed and described in `evidence/U/README.md`.
