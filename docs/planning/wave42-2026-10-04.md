## §P

1. **Off-board targets.** When Forge's open selection names cards that are not on any battlefield (a
   graveyard, exile, a library, a hand), show them in the decision area as a picker — art + name, the legal
   ones clickable — with Forge's own Cancel / "Done" when the selection allows zero (an optional "you may").
   Reproduce the lock first: a w42 scenario with Relentless Dead dying to Kozilek's Return (or any trigger
   targeting a graveyard card); prove the trigger can be answered AND declined.
2. **"You may sacrifice …" (W18).** Read on the wire what Forge sends for Sanctum of Ugin's trigger (a
   selection with min 0 naming the Sanctum? an optional-cost confirm?). If it is a selection whose only
   choice is the source card with min 0, present it as the yes/no pop-up (`ConfirmPrompt`), the answer sent
   as Forge expects. Prove with a scenario.
3. **The choice that was never shown (W16).** A cast or enters trigger whose choice opens as a board
   selection (Worldbreaker's target) shows the decision pop-up with Forge's own prompt text, as other asks do.
4. Unit tests per component; mutation-test 1.
5. **Done when:** the lock scenario answered and declined against real Forge (script + result), Sanctum and
   Worldbreaker each proven; `pnpm run check` 0.
