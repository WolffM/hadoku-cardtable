## Settled

- **Package names don't change.** `@hadoku/carddata`, `@hadoku/deck`, `@hadoku/draft` and `@hadoku/forge-wire` keep
  their names, so no import statement changes; only paths do. `git mv`, never copy-and-delete, so history follows.
- **`games/magic/LICENSE`** is GPL-3.0-or-later (the same text as the repo's GPL licence). Each moved package keeps
  its own `license` field and its Forge headers. The root licence stays as `docs/LICENSING.md` describes; update
  its "where Magic lives" lines.
- **The corpus.** The 184 MB `cards.jsonl` sits gitignored in `packages/carddata/data/` on the deploy tree. The
  tracker measured that **no server runtime code reads it**: the server's card data comes from
  `CARDTABLE_SCRYFALL_DIR` (`~/.local/share/cardtable/scryfall`). Only the carddata/deck CLIs default to the
  in-tree path. **Confirm this first** (step 0). If it holds, the host step is: the CLIs' default becomes
  `CARDTABLE_SCRYFALL_DIR`, and the old in-tree copy is left alone. **Never delete anything on a deploy tree**;
  the operator removes it later if they want. If it doesn't hold, stop, write what reads it, and don't move
  `carddata`.
- **The deploy is build-aside-and-swap** (c5bb6c9b): a fresh clone is built aside, so a gitignored file in the
  old tree never reaches the new one anyway. Measure what PPE does with the moved packages on its first deploy.
- **Delete what you replace**: old paths in scripts, CI, docs and layers. No wave numbers in source; no version
  edits; no AI attribution; never `/cutrelease` or `release.yml`; never `git stash`; never `pnpm install` in the
