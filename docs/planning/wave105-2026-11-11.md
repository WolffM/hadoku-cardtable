## The shared contracts (pinned here, so no lane waits)

**K's checkpoint** (`play/host.ts`, `play/game-adapter.ts`, platform):

```ts
// host.ts — Durable's checkpoint stops being `null`. It is opaque to the host: a game's own JSON.
export interface Durable { epoch: string; owners: (string | null)[]; checkpoint?: unknown }

// game-adapter.ts — already declared (w101): GameAdapter<Spec, Line, Cmd, Frame, Checkpoint = unknown>,
// classify(...) → { t: 'checkpoint'; cp: Checkpoint }, and restoreSpec(spec, cp). Nothing calls restoreSpec yet;
// K makes the shell call it.
```

- The shell keeps the newest `{ t: 'checkpoint' }` line's `cp` in the match's `Durable` and persists it with the
  record. Parking writes it; restore hands it to `restoreSpec`.
- Forge's park/restore (`play/parked.ts`, the turn-start snapshot) becomes Forge's `Checkpoint`: `state` is its
  snapshot. Its on-disk file decodes old records (decode-old test on a committed real parked file, sanitized).
- `readJvmRecord` decodes the match's checkpoint (H found it never decoded `snapshot`: an orphan re-attached after
  a restart lost its turn-start snapshot). That is K's.
- **K may refine this shape in its first commit and tells the manager, who relays it to S and C.**

**K's notice hook** (`GameSession`): `notice(kind: 'server-stopping', message: string)`. `Match.serverStopping`
moves behind it; the shell calls it, and Forge's session says it in words as today. The relay session (C) and the
toy game implement it (a relay match forwards it as a `{ t: 'notice' }` to every seat).

**`HostedMatch` moves out of `match.ts`** into `play/match/hosted.ts` (platform), K's commit, a pure move with
every importer rewritten. C composes `RelaySession` with `HostedMatch` and imports it from wherever it is on
origin/main when C rebases. If C needs it before K's move lands, C imports from `match.ts` and K's move commit
rewrites C's import line (K owns that one line).

**C's relay channel** (the bundle side, `@wolffm/rooms-protocol`'s `MatchChannel`, already published; read its
doc and `match-channel.ts`'s reference implementation before writing a line):
- `BundleSlot` builds `ctx.channel` from a relay socket when the room's game type says `runtime: 'relay'`.
- `GameTypeSpec` gains `runtime?: 'relay'` (`packages/shared/src/game-type-spec.ts`). Absent means today's

## §A — the agent cgroup fix, then the flat-field drop

The finding (`~/.cache/cardtable-manager/w103-A-closing.md`, FINDING): the agent enables `+memory` in its unit
cgroup's `subtree_control` for the draft bot's capped leaf (`apps/agent/src/cgroups.ts` `cap()`). With a live JVM
leaf beside it, cgroup v2's no-internal-process rule stops systemd from putting a restarted agent's main process
in the unit root: "Failed to spawn executor: Device or resource busy". Any agent restart with a live JVM after the
draft bot ran fails, old build included.
1. **The fix**, in `apps/agent`: the capped leaves live under a sub-tree of their own (`caps/`, with its own
   `subtree_control`), so the unit root's `subtree_control` stays empty and the agent's own process can always be
   placed. An agent that starts on a claw in today's state (root `+memory`, live leaves) migrates: it moves the
   leaves under `caps/` and clears the root, without killing a JVM. Unit tests on the fake cgroup tree
   (`agent.test.ts:396` pins today's `+memory` on the root; that assertion changes with the fix, and says why).
2. **claw-acceptance:** a case that restarts the agent with a live JVM **and** the draft bot running, and asserts
   the restart succeeds and the JVM is adopted, not fenced. Red on today's agent, green on the fix; record it.
3. **Hand the build to the manager.** The manager runs the rollout (below). A does not touch a claw.
4. **After every claw reports the new agent**, the flat-field drop: `packages/host-wire`'s `LaunchSpec` loses the
   flat fields, `runtimeOf` reads `runtime` only, the server stops sending them, the agent stops reading them. The
   wire pin test (e4e4c4982) changes with it, and says why. Prove with the jvm suites the selector picks for
   `remote/**` ×1 on claws, and a real match on one claw (the canary).
