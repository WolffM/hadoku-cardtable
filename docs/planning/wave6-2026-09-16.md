Protocol: `docs/handoff/w6.md`. One manager, **six sub-agents in parallel**, no

## §A — The product shell

What a person should meet at `hadoku.me/cardtable/`: not a Source switcher.

1. **A lobby.** Pick a cube (95 are in `cubes/`), set pod size, get a URL to send
   to friends, and see who has joined. The socket driver and the room server
   already do the work — `apps/ui/src/draft/socket.ts` — so this is a screen
   over an existing client, not new transport.
2. **Routing.** Lobby → draft → deck. Client-side is fine; the server already
   serves an SPA fallback for every path.
3. **The harness moves to `/debug`**, behind a flag. Do not delete it: its
   fixtures are what three waves of UI tests assert against, and deleting it
   deletes the regression net.
4. **Default the real route to the socket source.** `live` (in-process, solo vs
   bots) stays reachable from `/debug` and is genuinely useful — it is how you
   check a rendering change without a second browser.
5. Done when: a person who has never seen this app can start a pod, send a link,
   and reach a draft — asserted by a test that drives the lobby, not by a
   screenshot.

## §B — The draft screen becomes a product

The server already supports all three of these. Nothing in the UI shows them.

1. **Spectating.** `spectatorView` exists and is structurally cardless; the
   payload arrives already. Render the table, the seats and the counters, with
   no pack and no pool, and say plainly that you are spectating.
2. **Rejoin.** Seat reservations shipped in `rooms-protocol@0.38.111` with a
   TTL, and the server holds a seat on disconnect. The UI must show a seat is
   **held**, show reconnecting, and show recovery. A draft that silently freezes
   for 30 seconds looks broken even when it is working perfectly.
3. **The deck at the end.** A draft currently ends with a list of 45 names.
   `@hadoku/deck` writes real `.dck` files — surface a deck view and a download.
4. **Use `classifySeq`.** `gap` → resync, `duplicate` → drop and never resync,
   `epoch-change` → discard and refetch. The driver may already do this; the
   **UI** must not silently apply a stale payload.
5. Done when: a spectator payload renders with no cards and says so; a simulated
   disconnect shows held-seat and recovery states; and a finished draft exports
   a `.dck` that `parseDck` round-trips.

## §C — Formats: Standard, as of a date

The foundation for the operator's stated goal. **This lane ships no UI** — it
ships the question "was this card Standard-legal in September 2019?" answered
correctly.

1. The data is already there and was checked: the projection carries
   `legalities`, `released_at` and `set_type`. **`legalities.standard` is
   *today's* Standard and is the wrong answer for a historical format** — using
   it is the obvious trap and the reason this lane exists.
2. Derive the pool from set rotation: Standard at date D is the expansion sets
   in the rotation window at D. Encode the rotation rules and their exceptions —
   the model changed over the years, and a format that is silently wrong by one
   set is worse than one that refuses to answer.
3. **Cite a source for every rotation boundary**, in the code, the way
   `packages/carddata/src/dck.ts` cites Forge's own files. A rotation table
   nobody can check is a table nobody can fix.
4. Done when: `standardPoolAt('2019-09-01')` returns a card list whose set
   composition matches the documented rotation for that date, with at least
   **three** historical dates tested against cited boundaries, and a card that
   was legal then but is not now (and the reverse) asserted explicitly.

## §D — The deck library

1. Prebuilt decks as data: a deck is a `.dck` plus metadata (name, format, date).
   `@hadoku/deck` writes them; `@hadoku/carddata` parses them.
2. A deck **validates against a format pool** — lane C's output. Do not import
   lane C's code: take a pool as an argument. That keeps these two lanes
   independent, which is why they can run at once.
3. Round-trip everything: a deck written, re-parsed and re-written is
   byte-identical. Wave 3 proved the writer does this over all 95 cubes; hold it.
4. Done when: a prebuilt deck loads, validates against a supplied pool, reports
   *which* cards fail and why, and round-trips.

## §E — Ask watchparty for composable room chrome

Cardtable wants their room UI: chat, roster, presence, lobby, with our draft in
the middle. Today it cannot have it, and the reason is specific.

1. Write the ask from **our requirement**, not their internals: we need room
   chrome as composable exports with a slot, not a whole-app `mount()`.
2. **Report the packaging defect plainly**, with evidence:
   `@wolffm/watchparty-ui@0.38.115` declares `types: "./dist/index.d.ts"` and
   ships **0** `.d.ts` files, so every TypeScript consumer gets `any`. That is a
   defect whoever the consumer is, and it is cheap for them to fix.
3. Say what we will do meanwhile — build our own shell (lane A) behind a seam —
   so this reads as a roadmap ask and not a blocker.
4. Deliver it to `hadoku-watchparty` on a branch and **push it**. Committed is
   not delivered; that lesson cost Wave 2 a round trip.
5. Done when: the doc exists in both repos, the branch is pushed with an
   upstream set, and every claim in it was checked against the published
   tarball rather than their source tree.
