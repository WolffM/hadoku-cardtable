Protocol: `docs/handoff/w99.md`. One manager, one Sonnet sub-agent per lane, all lanes in parallel, no shared
files. Implementers leave changes uncommitted and stop. The manager verifies from artifacts, commits each lane,
and lands lane by lane. A lane counts as landed once PPE's `/health` carries it. Prod moves only at `/cutrelease`.

**Why:** the platform plan (artifact Jm5BXZj9xLPnpMGDwLSTKu; v2 at
`~/.cache/cardtable-manager/handoff-2026-11-07/platform-plan-v2.html`) has phases 1–4 on main. Phase 5, the match

## Settled — do not re-open in any lane

- **The next game could be anything, so there is no card kit: card-shaped code is Magic** (ruling 1, 2026-11-06).
  A platform file whose own logic draws cards, decks, art, drafts, pods or Forge frames is Magic, and that is
  reclassified, not wrapped.
- **The layer rule** (AGENTS.md, "Layer fence"). Each edge is fixed in one of three ways, in this order of
  preference:
  1. import the generic symbol from a platform home (`@hadoku/platform-wire`, `@hadoku/service-kernel`,
     `@hadoku/ui-shell`, or a platform file);
  2. reclassify the importing file as `magic`, when that is what the file is;
  3. put a narrow interface or an injection seam in the platform file, with the Magic half supplied from a
     `site`/`magic` composition root.

  **A reclassification is only allowed when it adds no new edge.** Every platform importer of the file must
  already be gone or be in the same lane. The tracker measured each candidate's importers; they are in the lane
  briefs.
- **Licence follows the layer (D26).** A file that moves to `magic` is GPL. Never add a GPL header to a `platform`
  file. Don't edit a `package.json` licence; `docs/LICENSING.md` has the mechanics.
- **Nothing a player sees changes.** The wire's shape is byte-identical, and saved rooms keep loading: the codec's
  fixtures (`room/codec.test.ts`) pass unchanged. No release note: there is nothing a player can feel.
- **Room logic belongs in watchparty's `rooms-*` packages** (operator, 2026-11-06). If L finds generic room logic in
  `lobby.ts` that `rooms-server` lacks, it **reports** it as a request to watchparty. It does not build a second
  copy in cardtable.
- **The physical move to `games/magic/` is phase 6.** No lane creates `games/` or moves files between packages.
  Moving files inside `apps/*/src` and inside `packages/shared/src` is fine.
- **Delete what you replace.** Every lane reports `made dead / deleted: <what>, −N lines`. New comments explain the
  code: no wave numbers, lane letters or ticket ids in source (those go in commit messages). A commit subject states
  what the commit contains.
- **Lines.**
  - A move is its own rename-only commit (`git diff -M --stat` shows a rename), so review sees code that moved
    apart from code that changed.
  - After the moves, each lane's non-test diff is **≤ +40 lines net**, and every added line is an import or a
    named seam.
  - Report jscpd and knip before and after: `npx knip --reporter json` (unused exports and types) and
    `npx jscpd apps/server/src apps/ui/src packages` (clone count); both are fetched by npx, neither is a repo dependency.
  - w92's exception, "+40, every line a named seam", is the ceiling, not the target.
- **No commit edits a version.** A new ledger row is `| AF??? |`.
