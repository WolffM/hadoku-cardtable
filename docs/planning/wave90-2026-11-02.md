   - Open `#/room/<id>` for a password room as a non-member, and for a room id that does not exist.
   - Assert the chat chrome is absent, and that no chat websocket or request for that chat id is opened
     (`page.on('websocket')` / request log).
   - Enter the right password: the chat appears.
   - A member reloading their own room still gets the chat on first paint (no regression).
2. NEW `rooms/joined.ts`: a tiny store of the room ids this tab has joined. `ConstructedScreen` marks one on a 200
   join and clears it on leave. `App.tsx`'s `room` case returns `null` until the store holds that id.
