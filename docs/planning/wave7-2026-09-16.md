## §A — Tier C: seat two AI players and watch the deltas

Wave 6 proved the *transport* and the *lobby*. `setGameView`, `openView` and
`applyDelta` — the whole state channel, and all of the actual work — **never
fired**. Lane F said so plainly and named the command that settles it.

1. Extend Wave 6's harness to seat two AI players and start a real game.
   `UnifiedNetworkHarness.java:178-240` already does exactly this; lane F's
   `docs/spikes/itoclient.md` has the reproduction.
2. Assert the client's `DeltaLoggingGuiGame` counted **non-zero** delta packets.
   A zero count is a failure, not a pass, and must not be reported as "it ran".
3. **The real question: does a delta survive a JSON round trip?** Serialise a
   captured `DeltaPacket` to JSON, deserialise it, and compare. `TrackableObject`
   carries a stable id and `DeltaPacket.makeDeltaKey` packs `(typeTag, id)` into
   one int (`DeltaPacket.java:61-70`) — so the question is whether the *values*
   round-trip, not the keys.
4. Report **what fails**, not just whether. A delta stream that round-trips
   except for three property types is a very different plan from one that does
   not round-trip at all.
5. **Never build in the vendored tree.** `FORGE_DIR` must point at a copy; the
   guard refuses the real one and now resolves symlinks.
6. Done when: `docs/spikes/tier-c.md` carries the reproduction, a **non-zero**
   delta count from a real match, a round-trip verdict with the failures named,
   and an updated week/month/quarter estimate. **"It does not round-trip" is a
   successful outcome** — it is the whole reason to run this first.

## §B — Make the fork ours: the Sentry DSN, then `case "server":`

The first Java this project has ever committed. Two changes, in this order.

1. **Strip the Sentry DSN first.** `Main.java:65` calls `Sentry.init` with
   upstream's **hardcoded DSN**, before it reads the mode argument, and *refills*
   an empty DSN — so no external config disables it. A dedicated server would
   report **our** crashes to the Forge project. The board has carried this as
   "todo — do not skip" since Wave 3. Do it before anything else runs.
2. Implement `case "server":` (`Main.java:111`, currently prints
   `"Not implemented."`). `case "sim":` beside it is the working precedent.
3. **Keep Forge's per-file copyright headers.** GPL-3, D2. Do not reformat files
   you are not changing; a diff nobody can read is a fork nobody can rebase.
4. Commit to **`WolffM/forge`** on a branch, push it, then bump the submodule
   pin here in a **separate commit** that says which upstream commit it moved to
   and why. If you bump past `2cd497c`, **re-derive the counts** `docs/` cites
   (`ProtocolMethod` 60, `ApiType` 206/202/199) and say so — they were all
   measured at that commit.
5. Done when: the fork carries both changes on a pushed branch; a build from a
   **copy** produces a server that starts headless; `assert_forge_pristine`
   passes on the vendored tree; and `grep -n 'Sentry.init' forge/.../Main.java`
   shows the DSN is gone rather than blanked.

## §C — The bridge wire contract

Lane F mapped the 38 required methods into three tiers. This turns that map into
a contract, and it can be written now because the tiering is settled even if
Tier C's *behaviour* is not.

1. A new `packages/forge-wire`: Zod schemas for the client↔server envelope,
   modelled on how `packages/shared` does it for the draft.
2. Tier A and Tier B are mechanical — 14 + 21 methods, mostly value objects.
   Model them. **Leave Tier C's three methods as an explicitly incomplete
   arm** with a comment pointing at lane A: shipping a confident schema for a
   channel nobody has exercised is how the next session inherits a wrong one.
3. `sideboard` is the one non-mechanical method in Tier B — it passes a pool and
   expects a deck. `@hadoku/deck` already models exactly that and round-trips
   Forge's `.dck` over all 95 cubes; use it rather than inventing a second model.
4. **GPL, not MIT.** This consumes Forge's protocol shape. D16's carve-out is
   for `room-ask` alone and does not generalise.
5. Done when: Tiers A and B are modelled with tests; Tier C is present and
   marked incomplete with a pointer to `docs/spikes/tier-c.md`; and nothing in
   the package imports from `forge/`.

## §D — A real past-Standard deck library

Wave 6 lane C shipped `standardPoolAt(date)` from Forge's 154 archived
snapshots, and lane D shipped a validator. Neither has any actual decks to work
on. This lane makes the operator's goal — *"recreate standard formats from years
past"* — testable with real data.

1. Pick **one** historical Standard and build a small library of real decks from
   it. One format done properly beats five half-done, and it is the one that
   proves the pipeline end to end.
2. Each deck: a `.dck` plus metadata (name, format, date, source). **Cite where
   each list came from** — a deck nobody can trace is a deck nobody can correct.
3. **Every deck must validate against `standardPoolAt` for its own date.** A
   deck that does not is either a bad transcription or a bug in the pool — find
   out which and say so; both are valuable and they are not the same finding.
4. No play surface. That needs PR-4 and is not this wave.
5. Done when: the library loads, every deck validates against its format's pool
   at its own date, each carries a citation, and a failing deck reports **which
   card** and **why**.
