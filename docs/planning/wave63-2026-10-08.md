# Wave 63 — the phases of a normal turn do not flash priority back and forth; on the opponent's turn the button is Auto Yield (this turn only), then Cancel Yield

Protocol: `docs/handoff/w63.md` carries it. One manager, one sub-agent per lane, all parallel, no shared
files. Implementers commit and stop; the manager verifies from artifacts (claws dispatches, never
`heavy.lock`), lands lane by lane with `scripts/land.sh`, and calls a lane landed when CI's `check` is
green on it and mgmt-api's log says `[deploy:cardtable] Verifying cardtable is serving <sha>` followed by
`Deploy completed`.

## Why

Playtest 15 (ledger AE7, AE8), 2026-10-08:
- AE7 *"i notice priority flashing back and forth in untap/upkeep/draw. that doesn't happen when passing
  through turns. it's a bit distracting, can you unify that behavior"*. End Turn arms Forge's pause
  exemption (`PlayBridge.java:1702` → `setPhaseDelayOff(true)`, `{t:'pace', skipPhaseDelay}`) so the
  phases fly; a normal turn's untap/upkeep/draw windows are not stop phases (`auto.ts:406`
  `DEFAULT_STOP_POLICY`), so the server auto-passes each (`match.ts:2029` `maybeAutoPass` → `auto-passed`)
  after Forge's own ~205 ms pause per phase, and each window's priority change reaches the UI (the rail's
  `data-whose`/current step, `LiveBoard.tsx:1145–1182` `PhaseRail` with `useCrawlGuard`; the pacer
  `pace.ts:80` `PACE_DELAYS_MS['phase']`) before the pass. WHICH element flashes is not measured.
- AE8 *"when it's the opponents turn the 'End turn' button should turn to 'Auto Yield' meaning that we
  auto-pass on whatever the opponent plays even if we did have a response and the game would have given us
  a chance. this is useful for hiding whether or not you have something, similar to how plays utilize that
  in arena. Auto Yield should only last for that turn and when clicking 'Auto Yield' it should turn to
  'Cancel Yield' to regain the ability to react normally."* `match.ts:2029` `maybeAutoPass` is the one place
  a seat's window is passed, from `autoPassReason(notes, s.policy)`; `s.fullControl` (`:2030`) is the
  precedent for a per-seat override set from the client (`live/match.ts:985` `setFullControl` →
  `MATCH_EVENTS.fullControl` → `fromClient`); the button cluster is `LiveBoard.tsx:2251–2305`
  (`live-button-end-turn` `:2269–2278`, `pressButton(match, 'cancel')`).

- AE11 *"in the chat it says 'Eisen' but in the game it correctly sees the name as 'Bella' … whats the right
  way to unify this? … i would prefer if this was unified. there should only be one source of truth"*. Two
  names: the edge-injected account display name (`x-user-name`, `apps/server/src/edge-auth.ts:99`
  `userNameOf`) fills the roster member (`http/rooms.ts:148` `name: userNameOf(req) ?? 'friend'`), the
  chat's join/left lines, and the Forge seat name (`http/routes.ts:1031` `names: players.map((p) => p.member.name)`);
  the watchparty package's per-app identity record (name + sprite, re-asserted on `IDENTITY_UPDATE` —
  `apps/ui/src/room/avatar.ts:33`'s note) is what the board draws. The per-app name is the duplicate.

## Settled — do not re-open in any lane

- **Measure first** (AE7): F's first commit is telemetry — a `client/phase` row per drawn priority change
  during a normal turn and during End Turn, from a real match on a claw — and the note names the element
  that flashed. The fix follows the measurement; the operator's words "unify that behavior" mean: a
  normal turn's auto-passed windows look like End Turn's (no visible back-and-forth), not that End Turn
  starts flashing.
- **Auto Yield** (AE8, the operator's words): on the opponent's turn the End Turn button (same testid,
  same place) reads **Auto Yield**; pressed, it reads **Cancel Yield** and the seat's every priority window
  this turn is auto-passed by the server, including a response window with their spell on the stack —
  whether or not the seat holds a response (the point is hiding it). Declare-blockers still opens (a
  block is not a response; Arena's yield does not skip it). The override expires when the turn number
  changes; Cancel Yield clears it at once. On my own turn the button is End Turn as today. No tooltip,
  no explanatory text.
- The server decides; the client only asks. `maybeAutoPass` consults the override before
  `autoPassReason`; the `auto-passed` log row carries `why: 'auto-yield'`.
