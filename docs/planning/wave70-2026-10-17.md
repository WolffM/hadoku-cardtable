## Wire contract (A and C build to it; C owns the schema)

In `packages/shared/src/draft.ts`, which `packages/shared/src/index.ts` already
re-exports. Do not touch `index.ts`; wave 71 owns that line.

```
GET  /api/drafts/:podId/mine   → 200 { pool: DraftCard[], deck: string | null }
                                 404 when the caller drafted no seat in that pod
PUT  /api/drafts/:podId/deck   body { dck: string }
                               → 200 { deck: string }
                                 400 { issues: string[] }   (gate's draft rule: ⊆ the caller's pool + basics)
```

- `deck` is `.dck` text: the caller's last saved build, or `null` before the
  first save.
- Both routes answer the **drafter**, by the same participant id that
  `draftPoolForMember` (`apps/server/src/http/routes.ts:319`) resolves.
- Both still answer after the drafter has left the pod, after the 120 s seat
  hold has run out, and after a server restart.

## §A — Deck editor

   component:
   - `limited`: the pool, basics, the 40-card floor; what `DeckBuilder` does today.
   - `sideboard`: a fixed 75, main ⇄ side swaps only, plus basics when the deck
     came from a drafted pool.

   deck is grouped by mana value with a curve count, and the pool/side is

   this lane.
2. **`#/deck/<podId>` loads and saves through C's contract.**

   - It saves with `PUT …/deck`, debounced, as cards move; the existing live
     check stays.
   - The AI-with-a-library-deck Start goes away. In its place, "Play" goes to
     the room list's create flow with the format preset to `draft:<podId>`

## §C — Pod store

A pool can be read only while the drafter holds a seat in the pod
(`routes.ts:300-317` explains why). Leaving vacates the seat with a 120 s hold,
and after that the gate answers "you have no seat in draft". Built decks are
stored nowhere.

1. **Once a pod's draft is complete, each drafter owns their seat's pool for
   good.**
   - `viewForParticipant` answers `kind: 'seat'` for them whether or not they
     are connected, through holds and restarts.
   - A seat nobody drafted (a bot's) stays unowned.
   - Before completion, nothing changes.
2. **Add the built-deck store**, per pod per drafter. It is persisted with the
   pod through `@hadoku/room-store` (draft half only) and restored at boot like
   `draftRestore.test.ts` restores pods.
3. **Add `apps/server/src/http/drafts.ts`** with the two routes in the
   contract, behind the friend gate like every `/api` route.
   - `PUT` checks with `gate.ts`'s draft rule (import it), so a saved deck is
     exactly what the table gate will accept at a start.
4. **Done when:**
   - `pnpm run check` exits 0;
   - a test leaves the pod, advances the clock past the hold, restarts the
     store, and both `GET …/mine` and the table gate's draft check still find
     the pool;
   - reverting step 1 fails that test (counts in the note).
